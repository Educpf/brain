Arch is famous for breaking a lot, mostly because of the low level control and how it's package manager `pacman` handles its updates.

This document highlights functions, ulitities and procedures that should be done in order to improve the overall system quality and reduce potential future breaks. Let's start with the basics:

# Check disk usage

To check DiskUsage with --summarize and --human-readable form ( can specify a single folder ):
```sh
    sudo du -sh /*
```
Because there are some ***pseudo-filesystems*** generated by the kernel, we may want to ignore those ( as access is sometimes not allowed ):
```sh
sudo du -xh --max-depth=1 \
  --exclude=/proc \
  --exclude=/sys \
  --exclude=/dev \
  --exclude=/run \
  /
```


Check current resource usage(task manager)
```sh
htop
```

Check system logs of the systems, errors and etc...
```sh
journalctl -xfe
```
# Temporary files

Delete the Trash ( location for deleted files via GUI )
```sh
rm -rf ~/.local/share/Trash/files/*
```
System cache ( not recommended to clear )
```sh
du -sh ~/.cache/ # Check its size
```
List of cached packages + space used`
```sh
sudo ls /var/cache/pacman/pkg/ | wc -l
du -sh /var/cache/pacman/pkg/    
```
Clear pacman cached packages ( up to 3 latest versions )
```sh
sudo paccache -r
```
Clear yay cache ( stored mainly on .cache/yay )
```sh
yay -Sc
```

# Packages

To list packages:
```sh
    pacman -Q # All 
    pacman -Qe # Explicitly installed
    sudo pacman -Qk # Broken
    # All ordered with extra info
    pacman -Qei | awk '/^Name/{name=$3} /^Installed Size/{print $4$5, name}' | sort -h
```

### Orphaned packages

Result of package already uninstalled, not needed by the system.
```sh
sudo pacman -Qdtq # List them
sudo pacman -Qtdq | sudo pacman -Rns - # Remove them
```
